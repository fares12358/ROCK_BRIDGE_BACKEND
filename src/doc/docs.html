Rock Bridge API Reference

A complete guide to integrating with the Rock Bridge backend. All requests should be made to the base URL: http://localhost:5000

Authentication

POST /api/auth/login
Public

Authenticates a user and returns an access token for subsequent requests.

Request Body (JSON)

{
  "email": "user@example.com",
  "password": "yourpassword"
}

Successful Response (200 OK)

{
  "message": "Login successful",
  "accessToken": "eyJhbGci...",
  "user": {
    "id": "64a...",
    "name": "John Doe",
    "email": "user@example.com"
  }
}
POST /api/auth/relogin
Token Required

Validates the existing token and issues a fresh one (Session Refresh).

Authentication

Header: Authorization: Bearer

OR Body: { "token": "..." }

Response (200 OK)

{
  "message": "Token refreshed",
  "accessToken": "eyJhbGci...",
  "user": { ... }
}
POST /api/auth/forgot
Public

Sends a password reset OTP to the specified email address.

Request Body (JSON)

{
  "email": "user@example.com"
}

Response (200 OK)

{
  "message": "Reset instructions sent to email"
}
POST /api/auth/reset
Public

Updates password using the OTP sent to the email.

Request Body (JSON)

{
  "email": "user@example.com",
  "otp": "123456",
  "newPassword": "new secure password"
}

Response (200 OK)

{
  "message": "Password reset successful"
}
GET /api/auth/me
Auth Required

Retrieves current authenticated user profile.

Authentication

Header: Authorization: Bearer

Response (200 OK)

{
  "user": {
    "id": "64a...",
    "name": "John Doe",
    "email": "user@example.com"
  }
}

Services

GET /api/services
Public

Retrieves all services listed on the website.

Response (200 OK)

[
  {
    "_id": "64...",
    "title_en": "Web Design",
    "title_ar": "تصميم المواقع",
    "description_en": "...",
    "description_ar": "...",
    "img": "http://localhost:5000/uploads/image.jpg",
    "createdAt": "..."
  }
]
POST /api/services
Auth Required

Adds a new service. Requires multipart/form-data.

Form Data

  • title_en (required) - English title
  • title_ar (required) - Arabic title
  • description_en (required) - English description
  • description_ar (required) - Arabic description
  • image (required) - Image file (JPEG, PNG, GIF)

Response (201 Created)

{
  "message": "Service created",
  "service": { ... }
}
DELETE /api/services/:id
Auth Required

Deletes a service and its associated image from storage.

Path Parameters

id - The unique ID of the service

Response (200 OK)

{
  "message": "Service deleted"
}

Media Library

GET /api/media
Public

Retrieves all uploaded images and videos.

Response (200 OK)

[
  {
    "_id": "64...",
    "title_en": "Hero Video",
    "mediaUrl": "http://...",
    "mediaType": "video",
    "size": 5242880
  }
]
POST /api/media
Auth Required

Uploads a new image or video file.

Form Data

  • file (required) - Media file
  • title_en (optional) - English title
  • title_ar (optional) - Arabic title
  • description_en (optional) - English description
  • description_ar (optional) - Arabic description

Response (201 Created)

{
  "message": "Media uploaded",
  "media": { ... }
}
DELETE /api/media/:id
Auth Required

Deletes a media file from the library and storage.

Path Parameters

id - The unique ID of the media

Response (200 OK)

{
  "message": "Media deleted"
}

Quote Requests

GET /api/quotes
Auth Required

Retrieves all customer quote requests.

Response (200 OK)

[
  {
    "_id": "64...",
    "name": "Jane Smith",
    "phone": "+123...",
    "email": "jane@example.com",
    "message": "I need a quote for...",
    "createdAt": "..."
  }
]
POST /api/quotes
Public

Submits a new quote request. Triggers email notifications to admin.

Request Body (JSON)

{
  "name": "Jane Smith",
  "phone": "+123...",
  "email": "jane@example.com",
  "message": "I need a quote for..."
}

Response (201 Created)

{
  "message": "Quote request created",
  "quote": { ... }
}
DELETE /api/quotes/:id
Auth Required

Removes a quote request from the database.

Path Parameters

id - The unique ID of the quote request

Response (200 OK)

{
  "message": "Quote deleted"
}
